# Winona Satishkumar — Design Portfolio

A responsive interdisciplinary design portfolio featuring selected visual communication and spatial design work.

Live site: <https://winonamax.github.io/winona-design-portfolio/>

## Selected projects

- **Hey Stupid, I Love You** — Album Cover / Visual Communication
- **Future Indoor Cat Park 2035** — 3D Environment / Spatial Design

The Living Portfolio homepage includes hand-drawn animal residents with click, tap, drag, keyboard, idle, and path-following interactions. The experience supports touch input and reduced-motion preferences.

## Built with

- Semantic HTML
- Responsive CSS
- Plain JavaScript
- No external frameworks or runtime dependencies

## Local preview

From this folder, run:

```sh
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

Only website-ready assets are included in this repository. Original course and project source files are not included.
